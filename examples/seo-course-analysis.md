# Example: SEO Course Analysis

## Source

A long-form course claims that an AI model can handle
professional SEO research, content writing, technical audits,
internal linking, and Search Console analysis.

## Evidence check

### Verified facts

No external primary sources were checked during this analysis.

### Source-reported facts

- The author states that the model was released recently.
- The author states that the model is cheaper and less verbose.
- The author describes an 11-module SEO workflow.

### Claims requiring proof

- The model can write ranking content at professional quality.
- The workflow can replace expert SEO work.
- Internal-linking recommendations will move pages from page two to page one.
- The workflow saves several hours per article.

### Unknowns

- Independent ranking case studies
- Traffic screenshots and before/after comparisons
- Full monthly API cost
- Whether the workflow works across different niches
- Whether AI-assisted content performs well over time

## Small test

Test one task only: keyword-intent classification.

1. Upload 100–200 keywords from a niche you understand.
2. Manually classify 20 of them.
3. Ask the model to classify all terms.
4. Compare the answers.
5. Check for invented search volumes or incorrect grouping.

A useful result is not:

> The model did SEO.

A useful result is:

> The model saved time on first-pass sorting,
> while a human corrected ambiguous cases.
